# luci-app-opengfw

OpenGFW 是一个基于 Linux Netfilter NFQUEUE 的高性能、灵活的深度报文检测 (DPI) 与流量过滤引擎。  
本项目是专为 **OpenWrt** 与 **iStoreOS** 打造的独立可视化管理控制面板（WebUI & LuCI 插件）。

---

## 📢 最新版本 v1.1.2-16 更新说明

对比上一版本（v1.1.2-14），本次更新主要包含以下两大改进：

### 1. 传统 VPN 协议识别与阻断管控
- **新增传统 VPN 协议按钮**：控制面板新增 WireGuard、IPsec、OpenVPN 等传统 VPN 协议卡片，支持一键切换【阻断 / 透视 / 未启用】；
- **修复底层漏网问题**：移除了底层防火墙对常见 VPN 端口的默认放行规则，避免流量绕过过滤，确保阻断严格生效；
- **端口放行与设备策略联动**：支持自定义放行端口（支持多端口与端口段），并可针对局域网指定设备设置独立的放行规则。

### 2. 控制面板 UI 界面优化
- **按钮统一单行排版**：修复了按钮文字被挤压换行的问题，操作按钮统一单行排列，界面更整洁紧凑；
- **状态标签独立外框**：为右上角“阻断生效中 / 透视中”状态增加了独立外框，杜绝与文字挤在一起；
- **界面字体渲染美化**：优化字体显示，消除粗糙锯齿感，视觉更清爽；
- **英文语言完整适配**：修复切换英文模式时透视看板仍有中文残留的问题。

## 🛠️ 主要功能介绍

### 1. 核心运行状态与实时数据监控
- 实时显示 OpenGFW 核心进程运行状态、进程 PID、运行时长与系统负载；
- 统计已处理数据包总数、已阻断数据包数、透视分析数、DNS 篡改数以及各类特定特征协议的拦截计数；
- 支持一键启动、停止、重启核心，以及免断网规则热重载（SIGHUP）。

### 2. 深度协议特征识别与防护 (Protocol Shield)
利用 OpenGFW 强大的分析器能力，对应用层深度协议进行识别与管控：
- **Shadowsocks / 裸 VMess+TCP (FET)**：基于全密文高熵识别算法（FET），检测并阻断无握手特征的纯对称加密全密文代理流量；
- **Trojan / VMess+TLS 伪装代理**：基于多阶数据包长度序列决策树状态机，深度识别伪装成普通 HTTPS 网站的 TLS-in-TLS 与 WebSocket 嵌套代理隧道；
- **SSH 远程终端连接**：识别内网设备发起的对外 SSH 握手并可按策略阻断未授权加密会话；
- **WireGuard / IPsec / OpenVPN**：深度识别基于 UDP 的 VPN 隧道握手报文，支持毫秒级特征熔断；
- **DNS 投毒与重定向 (Modifier)**：支持将被拦截域名的 DNS 查询结果实时劫持修改为 `0.0.0.0` 或指定应答 IP。

### 3. 三大运行模式一键切换
- **智能过滤**：按用户配置的规则库阻断黑名单域名、IP 与高危特征流，常规正常网络业务无感放行；
- **旁路观察**：仅对网络流量进行深度解析与透视记录，不执行丢包与切断操作，适用于网络行为审计与策略上线前评估；
- **全局防御**：全量开启针对高危加密穿透协议与异常特征流的严格封锁。

### 4. 实时协议透视与行为审计看板
- **实时会话流捕获**：毫秒级展示内网客户端发起的网络连接（源 IP:端口、目标 IP:端口、精准协议类型、处置动作、命中规则等）；
- **多维度检索与过滤**：支持按协议类型筛选、按动作筛选，支持 IP 与端口关键字即时搜索；
- **一键快捷联动策略**：在审计流中发现异常节点 IP 时，可直接点击行末的【+加白】或【-阻断】按钮，一键调出规则抽屉快速下发策略；
- **纯内存安全存储**：日志与审计记录 100% 保存在内存环形缓冲区中，**不对路由器 TF 卡或 EMMC 闪存产生读写 I/O**，保护存储芯片寿命。

### 5. 域名与设备策略管理
- 支持对 HTTP Host、HTTPS SNI 以及 DNS 请求域名进行细粒度管控（支持泛域名 `*.example.com`）；
- 支持黑白名单策略，支持按设备 IP / CIDR 网段独立绑定放行与阻断端口。

### 6. 软路由底层防火墙智能联动
- **自动双栈适配**：自动识别 OpenWrt / iStoreOS 系统的防火墙框架，完美兼容现代 `nftables (fw4)` 与传统 `iptables`；
- **NFQUEUE 智能接管**：自动在转发链中注入队列处理规则；
- **Bypass 保护机制**：当核心未启动或重载时，防火墙自动开启旁路绕行，确保局域网基础网络绝不断网。

## 🚀 安装方法

### 方式一：Web 界面安装（推荐）
1. 在上方表格中点击下载适合您设备架构的 `.ipk` 文件；
2. 登录路由器管理后台：
   - **iStoreOS**：进入 **系统 -> 文件传输**（或 **iStore 软件中心 -> 手动安装**），上传 `.ipk` 文件并点击“安装”；
   - **OpenWrt**：进入 **系统 -> 软件包 -> 上传软件包**，上传并执行安装；
3. 刷新页面，即可在顶部菜单或服务列表中看到 **OpenGFW**。

### 方式二：终端命令行安装
```bash
# 上传 ipk 至路由器的 /tmp 目录
opkg update
opkg install /tmp/luci-app-opengfw_1.1.2-16_*.ipk

# 启用并启动服务
/etc/init.d/opengfw enable
/etc/init.d/opengfw restart

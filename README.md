# luci-app-opengfw

OpenGFW 是一个基于 Linux Netfilter NFQUEUE 的高性能、灵活的深度报文检测 (DPI) 与流量过滤引擎。  
本项目是专为 **OpenWrt** 与 **iStoreOS** 软路由系统打造的独立可视化管理控制面板（WebUI & LuCI 插件）。

## 🛠️ 主要功能介绍

### 1. 核心运行状态与实时数据监控
- **进程与负载监控**：实时展示 OpenGFW 核心进程运行状态（运行中 / 已停止）、进程 PID、连续运行时长与系统负载；
- **指标实时统计**：实时统计已处理流量包总数、已阻断数据包数、透视分析数、DNS 篡改数，以及各特定代理特征的拦截计数；
- **免断网热重载**：修改规则后支持向核心发送 `SIGHUP` 信号实现毫秒级热更新，无需重启网络服务，局域网连接不中断。

### 2. 深度协议特征识别与防护 (Protocol Shield)
利用 OpenGFW 的多阶状态机分析器，对应用层深度协议进行精准识别与管控：
- **Shadowsocks / 裸 VMess+TCP (FET)**：集成全密文高熵识别算法（FET），检测无握手特征的对称加密纯密文代理流量并执行切断；
- **Trojan / VMess+TLS 伪装代理**：基于多阶数据包长度序列决策树状态机，深度识别伪装成正常 HTTPS 网站的 TLS-in-TLS 与 WebSocket 嵌套代理隧道；
- **SSH 远程终端会话**：识别内网设备向外发起的 SSH 握手，并可按策略阻断未授权加密终端会话；
- **DNS 投毒与重定向 (Modifier)**：支持将被拦截域名的 DNS 查询结果实时劫持修改为 `0.0.0.0` 或指定的警示页面 IP。

### 3. 三大运行模式一键切换
- **智能过滤**：按用户配置的规则库阻断黑名单域名、IP 与特征流，常规正常网络业务无感放行；
- **旁路观察**：仅对网络流量进行深度解析与透视记录，不执行丢包与阻断，适用于网络行为审计、故障排查与策略上线前评估；
- **全局防御**：全量开启针对高危加密穿透协议与异常特征流的严格封锁。

### 4. 实时协议透视与行为审计看板
- **会话流捕获**：毫秒级直观展示内网客户端发起的网络连接：
  - 发起客户端源 IP 与源端口；
  - 访问目标服务器 IP 与目标端口；
  - 识别出的具体协议类型（如 Trojan/VMess+TLS、Shadowsocks、SSH、TLS/HTTPS、域名等）；
  - 防火墙执行动作（阻断拦截 / 透视放行）；
  - 触发特征说明（包括 SNI 域名、命中规则名称等）。
- **多维度检索与过滤**：支持按协议类型筛选、按处置动作（阻断/放行）筛选，支持 IP 与端口关键字即时搜索；
- **一键策略联动**：在审计表格中发现异常连接，可直接点击行末的【+加白】或【-阻断】按钮，一键快速将该节点 IP 写入策略；
- **纯内存存储 (Zero I/O)**：日志与审计记录 100% 运行在内存环形缓冲区中，**不对路由器 TF 卡或 EMMC 闪存产生写盘操作**，彻底杜绝闪存磨损。

### 5. 域名策略管理
- 支持对 HTTP Host、HTTPS SNI 以及 DNS 请求域名进行细粒度管控；
- 支持泛域名通配符匹配（例如 `*.example.com`）；
- 支持黑名单拦截与白名单放行（白名单具有最高优先级，防止关键业务被误判）。

### 6. IP / CIDR 网段与设备策略
- 支持按目标服务器 IP 或 CIDR 网段（例如 `1.1.1.1`、`192.168.1.0/24`）添加策略；
- 支持指定内网源设备 IP 生效特定策略；
- 支持阻断与白名单放行动作。

### 7. 规则在线仿真测试器 (Rule Simulator)
- 内置规则匹配仿真器，在策略保存生效前输入待测试的域名或 IP；
- 实时计算并展示将会命中的规则名称、规则类型与预定处置动作。

### 8. 软路由底层防火墙智能联动
- **自动双栈适配**：自动识别系统防火墙架构，兼容 `nftables (fw4)` 与传统 `iptables`；
- **NFQUEUE 智能接管**：自动在系统转发链中注入流量分流规则；
- **Bypass 保护机制**：当核心未启动或热重载期间，防火墙自动开启旁路绕行，确保基础网络绝不断网；
- **环境自愈垫片**：内置针对精简固件缺少 NFQUEUE 参数的 iptables 兼容垫片，解决第三方固件的兼容性报错。

### 9. 多语言界面支持
- 内置简体中文、繁體中文与英文（English）无缝平滑切换。

## 🚀 安装方法

### 方式一：Web 界面安装
1. 下载适合您设备架构的 `.ipk` 文件；
2. 登录路由器管理后台：
   - **iStoreOS**：进入 **系统 -> 文件传输**（或 **iStore 软件中心 -> 手动安装**），上传 `.ipk` 文件并点击“安装”；
   - **OpenWrt**：进入 **系统 -> 软件包 -> 上传软件包**，上传并执行安装；
3. 刷新页面，即可在顶部菜单或服务列表中看到 **OpenGFW**。

### 方式二：终端命令行安装
```bash
# 上传 ipk 至路由器的 /tmp 目录
opkg update
opkg install /tmp/luci-app-opengfw_*.ipk

# 启用并启动服务
/etc/init.d/opengfw enable
/etc/init.d/opengfw start
